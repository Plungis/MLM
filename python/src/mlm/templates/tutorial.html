How MyAnonaSuite Works

Three powerful tools united into one cohesive ecosystem.

MyAnonaSuite brings together three essential tools for managing your MyAnonamouse (MaM) library and Audiobookshelf server:

H_

HeavyMLM

The Acquisition Engine: Finds books via bookmarks, snatchlists, or Goodreads/Notion reading lists, downloads them via qBittorrent with ratio safeguards, and neatly organizes them into library folders with clean series titles.

A_

ABSidekick

The Metadata & Review Matcher: Scans your Audiobookshelf library, cross-references book metadata across Audible, Open Library, and Google Books, fixes series numbering, and routes ambiguous matches to a visual Review Desk.

M$

MAM-Spender

The Bonus Economist: Automatically manages your MaM bonus points, keeping your account VIP status continuously renewed, purchasing Freeleech Wedges when safe, and logging bonus earnings history.

💡
Unified Workflow: When HeavyMLM finishes downloading and organizing a book, it can automatically notify ABSidekick to scan Audiobookshelf and match metadata instantly!

Connecting to MyAnonamouse (MaM Cookie)

Authenticate with MyAnonamouse using your browser session cookie.

  1. Log into MyAnonamouse in your web browser (Chrome, Firefox, Edge, etc.).
  2. Open Developer Tools by pressing F12 (or right-click anywhere and choose Inspect).
  3. Go to the Application tab (in Chrome/Edge) or Storage tab (in Firefox).
  4. In the left sidebar, expand Cookies and select https://www.myanonamouse.net.
  5. Find the cookie named mam_id and copy its entire alphanumeric value.
  6. Paste the cookie into the MaM ID Cookie field in Configuration or set mam_id = "..." in your config.toml.
🔒
Privacy & Security: Your session cookie is stored locally on your server only. It is never transmitted anywhere other than direct, encrypted HTTPS calls to MyAnonamouse API endpoints.

Configuring qBittorrent & Library Paths

Set up automated torrent handling, ratio rules, and file organization.

HeavyMLM monitors qBittorrent to detect when downloads finish and automatically places them into your organized media directory.

1. qBittorrent Web UI

In qBittorrent settings (Options → Web UI), enable the Web User Interface. Note your port (default 8080), username, and password.

2. Categories & Tags

Create categories in qBittorrent such as Audiobooks and Ebooks. HeavyMLM will tag and categorize new downloads automatically.

3. File Organization (Hardlinking)

HeavyMLM uses hardlinks by default. This creates a beautifully structured folder for Audiobookshelf (e.g. Author/Series #1 - Title/book.m4b) without using double disk space or stopping your seeding in qBittorrent!

4. Ratio & Slot Safeguards

Under Configuration → Download policy, configure your Minimum ratio, Minimum open slots, and Wedge-first settings so you never risk your account status.

04

Audiobookshelf & ABSidekick Matching

Automatically match metadata, fix series, and fetch high-resolution covers.

  1. In Audiobookshelf, go to Settings → Users → your user → API Token and generate/copy a token.
  2. Open ABSidekick Config, enter your Audiobookshelf Server URL and paste the API Token, then click Test & Connect.
  3. Select your target Audiobookshelf library from the dropdown.
  4. Choose your Metadata Providers:
    • Audible: Fast, native audiobook metadata, chapters, and narrators.
    • Open Library: Enter your contact email to enable polite, high-rate public book lookups.
    • Google Books: Optional native API key for comprehensive ebook and author metadata.
  5. Enable Auto-Sync: In Configuration, check Auto-sync with ABSidekick when new books are organized. When HeavyMLM places a book, ABSidekick will automatically scan and match it without manual clicks!

MAM-Spender (Automated Bonus Management)

Keep your VIP renewed and accumulate Freeleech Wedges automatically.

MAM-Spender inspects your MaM bonus point balance periodically and executes purchases according to your rules:

Auto VIP Renewal

Automatically purchases 4-week VIP renewals when your remaining VIP duration drops below your chosen threshold (e.g. 7 days).

Freeleech Wedges

Buys freeleech wedges when you have points to spare, ensuring you always have wedges ready for ratio-free downloads.

Point Safety Buffer

Configurable reserve (e.g. 50,000 points) that the spender will never spend past, protecting your balance for emergencies.

History & Graphing

Visit Analytics and History to see your points earned per hour and past purchases.

Request Portal & Critical Web Security Guide

How to safely share a request portal with family and friends.

⚠️
CRITICAL SAFETY WARNING: NEVER EXPOSE PORT 3157 DIRECTLY TO THE PUBLIC INTERNET

The primary MyAnonaSuite interface on port 3157 contains powerful administrative controls (file deletion, torrent queue management, account cookies, and configuration files). Exposing port 3157 directly without an isolated reverse proxy or firewall can allow unauthorized access to your private data and download clients.

How the Request Portal Protects You

MyAnonaSuite includes a built-in Domain-Isolated Request Portal designed specifically for safe public sharing:

  • Domain Routing: When accessed via a custom domain (e.g. requests.yourdomain.com), the server strictly locks down all administration routes (blocking /config, /operations, /suite/*, and API controls) and serves only the search and request form.
  • Named Requester Accounts: Require each friend or family member to log in with their own password, tracking who submitted every book and preventing spam.
  • Rate Limiting: Enforces per-minute rate limits to protect your server and MaM account from automated flooding.

Reverse Proxy Setup Instructions

Nginx Proxy Manager

  1. Create a Proxy Host pointing requests.yourdomain.com to http://your-server-ip:3157.
  2. Enable Websockets Support and Block Common Exploits.
  3. Under the SSL tab, issue a Let's Encrypt certificate and enable Force SSL.

Caddy Server

requests.yourdomain.com {
    reverse_proxy localhost:3157 {
        header_up X-Forwarded-Host {host}
        header_up X-Forwarded-Proto {scheme}
    }
}

Cloudflare Tunnels

Create a Public Hostname routing requests.yourdomain.com to http://localhost:3157. Under HTTP Settings, ensure the original Host header is forwarded.

Portal Configuration

In Configuration → Request portal, check Enable request portal, enter requests.yourdomain.com under Custom request domains, and create user accounts.
